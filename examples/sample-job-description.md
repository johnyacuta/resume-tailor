# Sample job description (fictional)

**Role:** Platform Engineer  
**Company:** Northstar Systems (fictional)  
**Work arrangement:** Hybrid

## Responsibilities

- Build and operate Kubernetes platforms for application teams.
- Maintain cloud infrastructure using infrastructure as code.
- Improve deployment automation and service observability.
- Partner with engineering teams to improve platform reliability.

## Required qualifications

- Experience operating Kubernetes in production.
- Experience with Terraform or a comparable infrastructure-as-code tool.
- Experience building CI/CD automation.

## Preferred qualifications

- Experience with Azure Kubernetes Service (AKS).
- Experience with Prometheus or Grafana.
- Experience designing reusable platform components.
