# Illustrative v1.0 output summary

This fictional example demonstrates the concise evidence notes that accompany a tailored resume. Its input is in [sample-candidate-evidence.md](./sample-candidate-evidence.md), and the fictional posting is in [sample-job-description.md](./sample-job-description.md). It is not a real candidate resume or a hiring recommendation.

**Tailored resume:** `Jordan-Lee-Platform-Engineer-tailored.pdf` (example filename only; no file is included)

**Evidence used**

- Reframed the resume's production Kubernetes operations and Terraform module work to emphasize platform engineering and infrastructure as code.
- Added the AKS landing-zone experience across development, staging, and production environments, based on the portfolio's fictional "Azure Platform" project page.
- Kept a CI/CD contribution as a contribution; the sources did not establish sole ownership.

**Gap or caveat**

- The sources reviewed did not show Prometheus or Grafana experience. Neither tool was added to the resume.
- The resume described Azure experience but did not support AWS production experience; no AWS claim was added.
- The example assumes a document tool can edit and export the original DOCX. A real assistant must confirm that an output file exists and inspect it before linking to it.

No match percentage is included. This summary describes evidence found in the reviewed sources; it does not predict hiring outcomes.
