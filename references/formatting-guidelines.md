# Formatting guidelines

The existing resume is the design baseline. Preserve its identity while making only the content and layout changes needed for role relevance and readability.

## Preserve by default

- Overall section order, visual hierarchy, and general page layout.
- Existing font family, sizes, colors, margins, spacing, and bullet treatment.
- Header, footer, contact details, and page numbering.
- Role titles, employers, dates, and established section labels.

Reorder or condense content only when it improves relevance without changing meaning or hiding material history. Do not add a new template or redesign the resume unless the user asks.

## Edit safely

- Never overwrite the original resume. Create a separate, clearly named output.
- Prefer editing an available DOCX when it preserves styles and layout; export a separate PDF if reliable export is available.
- For a PDF-only source, first determine whether the document can be edited faithfully. PDF-to-DOCX conversion can alter columns, spacing, fonts, and page breaks.
- Preserve the original page count when practical, but do not make text uncomfortably small or remove useful experience just to force a page count.
- Keep text selectable and readable where the document tools allow it.
- Inspect the generated document visually when possible. Check page breaks, clipping, columns, bullets, headings, links, headers, and footers.

## Be explicit about limitations

Do not promise pixel-perfect matching. If extraction, editing, or visual inspection is unavailable or unreliable, explain the limitation and do not claim formatting was preserved or a PDF was generated. Provide the tailored text or a safely editable draft instead, and identify what the user needs to review or export.
